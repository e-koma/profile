# About
大規模サーバを安定運用させるサーバサイド/インフラエンジニアです。

私の強みは次の3点です。
- 大規模トラフィックに対するサーバ負荷対策
  - AWS Summit Tokyo 2019の [登壇資料](https://pages.awscloud.com/rs/112-TZM-766/images/I3-04.pdf) のように、100万req/min以上の大規模トラフィックが見込まれる、スマホのセールスランキング上位のアプリのシステムにおいて、サーバ負荷対策を徹底的に行い改善してきた実績があります。これ以外のシステムでも複数のシステムでOS/DB/アプリケーションチューニングの経験があり、多くの実績を残しています。
  - ソーシャルゲーム7タイトルおよび、ミッションクリティカルシステムの本番運用経験があるため、システム障害時のトラブルシュート力、すなわち問題検知から切り分け、問題特定、対処案提示、対処、再発防止まで一気通貫で推進できます。万が一大規模な障害が発生しても「オレにとってこの状態は昼下がりのコーヒーブレイクと何ら変わらない平穏なものだ」
- システムの非機能要件をリリース品質まで高めるアーキテクト能力
  - システム設計・構築
    - マルチクラウド(AWS/GCP)で最適な構成を設計できます
    - クラウドネイティブ/コンテナネイティブなシステムを0から完全にコード管理された状態で構築することができます。 新しい技術導入に関しては、必要に応じてPoC検証を取り入れ、机上の検討と実運用におけるバランスを取ることができます。
  - 品質向上
    - 複数のシステムで性能改善/可用性向上/運用自動化/監視・復旧自動化を行い、非機能要件をプロダクション品質まで引き上げてきました。
  - コスト削減
    - 数十個のAWSアカウントの契約、管理や、スポットインスタンスを本番導入するなどの実績があり、アーキテクチャのコスト削減ノウハウが豊富です。
  - セキュリティ
    - 40個のAWSアカウント、400個のGCPプロジェクトにおいて、セキュリティポリシーに違反した設定を自動的に検知し、セキュリティ監査を自動化してきた実績があります。
    - 組織のワークフローに沿って、柔軟にカスタマイズした運用を構築できます。
- 主体性およびチーム/プロダクトを推進する力
  - 正社員時代は仕事を振る上司のような存在は(意図的に)いませんでした。ビジネス価値を最も出せるプロジェクトに自ら参画し、自ら価値を出していく働き方をしていました。指示待ちではなく、ビジネスインパクトの大きいテーマに自ら入り、課題定義から実行まで進めてきました。マネージャー不在でも、リーダーシップを取って前進させます。
  - プロジェクト内では自ら課題を定義し、自ら仕事を進めています。マネージャーレスで勝手に仕事が進んでいくタイプです。チームリーダーがいなければ、自らその役割を担うこともあります。
  - システム開発のクロージング能力。プロジェクトのリリースを迎えた経験が豊富なので、リリース完了まで責任を持ってクローズしてきた経験が豊富です。
